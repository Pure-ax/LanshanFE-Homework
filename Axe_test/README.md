# Axe

Axe是仿 Figma 和 Canva可画 的一个画布绘图网页小项目。

## 项目背景

该项目是为了完成蓝山工作室寒假考核，也是为了在寒假期间能够持续学习，提升自己。

## 主要功能

- 功能1: 绘制和渲染简单的几何图形和文字输入
- 功能2: 可以进行简单的画笔绘图
- 功能3: 可以进行简单的外部图片导入和滤镜修改
- 功能4：支持png文件导出

## 技术栈

- vue3 + pinia + vue router + canvas + Element Plus + node.js(虽然已经快忘完了，这个项目也没用到..)

## 安装依赖

```sh
# 在项目所在目录运行以下命令
npm install pinia vue-router
# 如果vite包缺失，在项目所在目录运行 npm install @vitejs/plugin - vue --save - dev
```

### 运行

```sh
# 在项目所在目录运行以下命令
npm run dev
```
